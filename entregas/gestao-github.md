# Gestão do repositório com GitHub

## Issues

Os issues foram utilizados para registrar tarefas técnicas relevantes e critérios de conclusão:

- #1 Implementar SPA com roteamento por hash.
- #2 Persistir interesses dos projetos com localStorage.
- #3 Modularizar JavaScript com ES6 Modules.
- #4 Documentar gestão do repositório com issues e pull requests.

Os três primeiros foram encerrados como `completed` após a verificação de que suas respectivas implementações estavam presentes no código.

## Pull requests

O fluxo de integração segue a estratégia GitFlow documentada no projeto. Alterações preparadas em `develop` são revisadas por pull request antes de chegar à `main`.

Este documento foi produzido na branch `develop` e integrado à `main` por PR, criando um registro verificável do processo de revisão e merge mesmo em um projeto individual.

## Milestone e release

A versão de referência desta etapa é `v1.0.0`, representada pela branch `release/v1.0.0`, pelo `CHANGELOG.md` e pela documentação de versionamento semântico. Os issues concluídos correspondem aos objetivos técnicos consolidados nessa entrega.
