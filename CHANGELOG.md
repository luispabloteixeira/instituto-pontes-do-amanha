# Changelog

Todas as alterações relevantes deste projeto são registradas neste arquivo.

O projeto segue Semantic Versioning (SemVer) no formato MAJOR.MINOR.PATCH e adota Conventional Commits para padronizar o histórico.

## [1.0.0] - 2026-09-12

### Added
- Navegação Single Page Application por hash.
- Templates dinâmicos para geração de cards de projetos.
- Persistência de interesses com localStorage e JSON.
- Validação dinâmica de formulários com feedback visual.
- Componentes de feedback: alertas, badges, toast e modal.
- Estrutura modular com ES6 Modules, import e export.
- Estrutura de pastas separada em html, css, imagens e js.
- Estratégia GitFlow com main, develop, feature, release e hotfix.

### Changed
- Reorganização do código JavaScript para reduzir acoplamento.
- Ajustes de acessibilidade em menus, formulários e componentes interativos.
- Adequação do projeto para publicação e acesso pelo GitHub Pages.

### Fixed
- Sincronização do estado visual dos menus com aria-expanded.
- Ajustes na validação nativa e complementar do formulário.
